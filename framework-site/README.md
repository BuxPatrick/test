# framework-site

A website built with a framework (Next.js / React) that deliberately has no
styling. No CSS files, no CSS-in-JS, no UI library — just default browser
rendering of raw HTML elements.

## Pages

- `/` — home
- `/about` — about
- `/products` — a plain HTML table of products
- `/contact` — a form with local state (no backend)

## Run it

```
npm install
npm run dev
```

## Build it

```
npm run build
npm start
```
